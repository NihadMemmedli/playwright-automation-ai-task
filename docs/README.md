# Documentation

This documentation is organised by **what you're trying to do**, following the [Diataxis](https://diataxis.fr) framework. Pick the entry point that matches your need:

| If you're… | Read |
|---|---|
| new to the framework and want to see it work | **[Tutorial](./tutorial.md)** — a 10-minute walkthrough of the self-healing demo. |
| trying to accomplish a specific task | **[How-to guides](./how-to.md)** — running tests, AI healing, Docker, CI, troubleshooting. |
| looking up a flag, script, or env var | **[Reference](./reference.md)** — npm scripts, env vars, tags, project structure. |
| trying to understand *why* it's built this way | **[Explanation](./explanation.md)** — design decisions, healer architecture, trade-offs. |
| chasing a flake | **[STABILITY.md](../STABILITY.md)** — measurement, triage workflow, quarantine. |

The four documents don't overlap. A task that needs cross-cutting context will link you between them.
